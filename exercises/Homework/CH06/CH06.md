一、案例简介

这个案例做的是机器翻译任务。程序先读取平行语料，再把源语言和目标语言句子变成 token 序列，然后送进 Translator 模型训练。因为它直接调用了 PyTorch 的 nn.Transformer，所以比较适合从整体上分析数据输入、模型计算和结果输出的过程。

二、执行流程总览

训练阶段的主流程可以概括为：

Multi30k 数据集
 -> spacy 分词
 -> 构建源语言和目标语言词表
 -> 给句子加上 `<bos>` 和 `<eos>`
 -> pad_sequence 对齐长度
 -> DataLoader 按 batch 输出 src 和 tgt
 -> Translator.forward
 -> 词嵌入 Embedding
 -> 位置编码 PositionalEncoding
 -> nn.Transformer
 -> Encoder 提取源句上下文表示
 -> Decoder 结合目标序列和源句表示进行解码
 -> 线性层 ff 输出词表上的 logits
 -> CrossEntropyLoss 计算损失
 -> backward 反向传播
 -> optim.step 更新参数

推理阶段的主流程可以概括为：

用户输入源语言句子
 -> 转成 token id
 -> model.encode 得到 memory
 -> 用 `<bos>` 作为起始符
 -> 循环调用 model.decode
 -> 取最后一个位置的输出
 -> 线性层 ff 计算下一个词的概率
 -> 选择概率最大的词
 -> 拼接到结果序列末尾
 -> 直到生成 `<eos>` 结束

三、执行过程分析

1. 数据准备过程

程序先在 data.py 里的 get_data 函数中读取 Multi30k 数据集，然后分别做分词、建词表，并给句子加上 `<bos>` 和 `<eos>`。因为句子长短不同，所以还要用 pad_sequence 做补齐，这样才能组成 batch 张量。这样一来，原始文本就被整理成了模型可以直接处理的数字序列。

2. 模型构建过程

模型主体写在 model.py 的 Translator 类里。它先用嵌入层把 token id 变成词向量，再加上位置编码。后面程序把源序列和目标序列送进 nn.Transformer，内部还是经典的 Encoder-Decoder Transformer 结构：

- Encoder 部分由多层编码器堆叠组成，每层都包含多头自注意力和前馈网络。
- Decoder 部分由多层解码器堆叠组成，每层包含掩码自注意力、编码器到解码器注意力以及前馈网络。
- 最后再经过线性层 ff，把每个位置的隐藏表示投影到目标词表维度，得到每个词的预测分数。

3. 训练过程

训练入口主要在 main.py 的 main 和 train 函数里。每次读到一个 batch 之后，程序先把目标序列分成两部分：

- tgt_input = tgt[:-1, :]，作为解码器输入。
- tgt_out = tgt[1:, :]，作为模型应该预测的正确答案。

这种做法就是 teacher forcing，也就是让模型根据前面已经给出的真实词去预测下一个词。

然后程序调用 create_mask 构造四类掩码：

- src_mask：源序列的基本掩码。
- tgt_mask：目标序列的下三角掩码，用来阻止当前位置看到未来词。
- src_padding_mask：标记源序列中的 pad 位置。
- tgt_padding_mask：标记目标序列中的 pad 位置。

这里最关键的是 tgt_mask，它会挡住未来词，避免解码器提前看到答案。掩码准备好以后，程序执行 logits = model(src, tgt_input, ...)，再用 CrossEntropyLoss 计算损失，最后通过 loss.backward 和 optim.step 完成参数更新。

4. 推理过程

推理入口在 inference 和 greedy_decode 函数里。程序先读取训练好的模型参数，再把用户输入的句子转成 token id 序列。因为推理时没有标准答案，所以解码器只能一步一步往后生成。

greedy_decode 的过程比较直接：先用 model.encode 对源句子编码得到 memory，再把 ys 初始化成只包含 `<bos>` 的序列。然后程序在循环里不断构造 tgt_mask，调用 model.decode 预测下一个词，再把概率最大的词接到 ys 后面。如果生成了 `<eos>`，推理就结束。这种方法叫贪心解码，实现简单，但结果不一定是最优的。

四、关键函数注释详解

1. get_data

这个函数的作用是完成整个数据预处理流程。它负责读取数据集、创建分词器、建立词表、定义文本到张量的转换方法，并生成 DataLoader。可以把它理解为“把原始文本变成模型输入”的总入口。

2. create_mask

这个函数的作用是生成训练时必须使用的各种掩码。它既要处理 pad token，又要处理未来信息屏蔽问题。其中 tgt_mask 最重要，因为它保证了解码器的自回归特性。

3. Translator.forward

这个函数是模型前向传播的核心入口。它先把 src 和 trg 分别做词嵌入和位置编码，再送入 nn.Transformer，最后用线性层映射到词表维度。这个函数体现了从输入序列到预测分布的完整计算链。

4. train

这个函数负责一轮训练中的单 batch 处理过程。它完成目标序列拆分、掩码创建、前向传播、损失计算、梯度清零、反向传播和参数更新，是最能体现训练机制的函数。

5. greedy_decode

这个函数负责推理阶段的逐词生成。它先编码源句，再不断根据当前已生成结果预测下一个词。这个函数非常适合说明 Transformer 在推理时为什么仍然是一步一步生成的。

五、结合源码的核心代码注释

为了更贴近源码，下面再对几个核心函数做简单注释说明。

1. get_data 的核心逻辑

```python
train_iterator = Multi30k(split="train", language_pair=(src_lang, tgt_lang))
src_vocab = build_vocab_from_iterator(...)
tgt_vocab = build_vocab_from_iterator(...)

def _tensor_transform(token_ids):
	return torch.cat([<bos>, token_ids, <eos>])

def _collate_fn(batch):
	src_batch.append(src_lang_transform(src_sample))
	tgt_batch.append(tgt_lang_transform(tgt_sample))
	return pad_sequence(src_batch), pad_sequence(tgt_batch)
```

这段代码主要完成三件事：读取训练集、建立词表、把句子整理成带有 `<bos>` 和 `<eos>` 的张量。_collate_fn 的作用就是把一个 batch 里的句子补齐后再打包输出。

2. create_mask 的核心逻辑

```python
src_seq_len = src.shape[0]
tgt_seq_len = tgt.shape[0]

tgt_mask = generate_square_subsequent_mask(tgt_seq_len, device)
src_mask = torch.zeros((src_seq_len, src_seq_len)).type(torch.bool)

src_padding_mask = (src == pad_idx).transpose(0, 1)
tgt_padding_mask = (tgt == pad_idx).transpose(0, 1)
```

这段代码是专门用来生成掩码的。tgt_mask 用来挡住未来词，src_padding_mask 和 tgt_padding_mask 用来标记 pad 位置，避免模型把补齐符号也当成正常词。

3. Translator.forward 的核心逻辑

```python
src_emb = self.pos_enc(self.src_embedding(src))
tgt_emb = self.pos_enc(self.tgt_embedding(trg))

outs = self.transformer(
	src_emb, tgt_emb,
	src_mask, tgt_mask,
	None, src_padding_mask,
	tgt_padding_mask, memory_key_padding_mask
)

return self.ff(outs)
```

这里可以看出前向传播的主线：先做词嵌入和位置编码，再送进 self.transformer，最后通过 self.ff 输出目标词表上的预测分数。

4. train 的核心逻辑

```python
tgt_input = tgt[:-1, :]
src_mask, tgt_mask, src_padding_mask, tgt_padding_mask = create_mask(...)
logits = model(src, tgt_input, ...)

optim.zero_grad()
tgt_out = tgt[1:, :]
loss = loss_fn(logits.reshape(-1, logits.shape[-1]), tgt_out.reshape(-1))
loss.backward()
optim.step()
```

这里最重要的是把目标序列拆成输入和正确答案两部分。后面再依次完成建掩码、前向传播、计算损失、反向传播和参数更新。

5. greedy_decode 的核心逻辑

```python
memory = model.encode(src, src_mask)
ys = torch.ones(1, 1).fill_(start_symbol)

for _ in range(max_len - 1):
	tgt_mask = generate_square_subsequent_mask(ys.size(0), DEVICE)
	out = model.decode(ys, memory, tgt_mask)
	prob = model.ff(out.transpose(0, 1)[:, -1])
	_, next_word = torch.max(prob, dim=1)
	ys = torch.cat([ys, next_word], dim=0)
```

这段代码体现了推理时的逐词生成过程：先编码源句，再以 `<bos>` 作为起点，不断预测下一个词并拼接到结果后面，直到生成 `<eos>` 为止。
